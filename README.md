# Pilgrim QuickFill for TTD ⚡

A high-speed, privacy-first Chrome Extension (Manifest V3) designed to securely store and autofill pilgrim and devotee details on official Tirumala Tirupati Devasthanams (TTD) booking portals (`ttdevasthanams.ap.gov.in`, `tirupatibalaji.ap.gov.in`).

---

## 🌟 Key Features

- **⚡ Instant 1-Click Autofill (Tier 1):** Fills all pilgrim details (Name, Age, Gender, Photo ID Proof, Photo ID Number, Gothram) and general contact fields (Email, Mobile, State, City, Country, Pincode) in sub-second speed.
- **🛡️ 100% Privacy & Local Storage:** All profile and sensitive data (e.g., Aadhaar, phone number) are encrypted locally using **AES-256-GCM** with a user-defined passphrase. Zero remote analytics, zero third-party telemetry, zero external network calls.
- **⚛️ Single Page Application (SPA) & Next.js Support:** Built-in React `_valueTracker` integration and synthetic event dispatching (`input`, `change`, `blur`) ensure fields persist across reactive frameworks without being cleared.
- **🎯 Dynamic Custom Field Mapping:** Visual, in-DOM interactive element picker to map custom fields or adapt to portal layout changes without code edits.
- **📋 Fallback Assistants (Tiers 2 & 3):**
  - **Quick Paste Controller:** Step-by-step guided clipboard paste with auto-advance (`Alt+S`).
  - **Type Assist:** Simulated human keystrokes for hostile portals that block clipboard events.
- **🔒 Anti-Tampering Security Guardrails:** Never automates CAPTCHA solving or payment submission (strictly brings CAPTCHA into focus).
- **⏰ Live IST Clock:** Built-in synchronized Indian Standard Time (IST) clock with darshan/seva quota drop countdown.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/)

### Installation & Build

1. Clone the repository:
   ```bash
   git clone https://github.com/Venu3421/AutofillExtension.git
   cd AutofillExtension
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run automated tests:
   ```bash
   npm test
   ```

4. Build the extension bundle:
   ```bash
   npm run build
   ```

5. (Optional) Create production ZIP for distribution:
   ```bash
   npm run zip
   ```

---

## 📦 Loading in Chrome

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** toggle in the top-right corner.
3. Click **Load unpacked**.
4. Select the `dist/` directory generated by `npm run build`.
5. Pin the extension to your toolbar and click the icon to configure your profile and pilgrims.

| Shortcut | Action |
